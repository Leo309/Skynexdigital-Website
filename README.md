# SKYNEX DIGITAL Official Website

This is the official website for SKYNEX DIGITAL (SKYNEX GLOBAL COMMERCE & TECH INC.), an AI-powered marketing automation company based in British Columbia, Canada with offices in New York City and Metro Vancouver.

## About SKYNEX

SKYNEX builds AI-powered tools that automate repetitive marketing workflows. From checking brand visibility in AI search to managing partnerships, we build products for the new era of marketing.

## Website Features

- Modern, responsive design built with Next.js 15 and Tailwind CSS
- Dark/light mode support with seamless transitions
- Interactive UI elements powered by Framer Motion
- SEO optimized with metadata API and structured data
- Responsive layouts for all devices
- Fast performance with server components
- Contact form for inquiries
- Comprehensive company and service information

## Our Products

- **GeoGrade.ai**: AI agent that simulates real users to check your brand's visibility in AI search tools like ChatGPT, Perplexity, and Gemini. Available at [geograde.ai](https://geograde.ai)
- **CollabZen.ai**: Lightweight CRM for managing partnerships, collaborations, and campaigns. Available at [collabzen.ai](https://collabzen.ai)
- **Real Return Analyzer**: Track inflation impact on purchasing power with data-driven insights.

## Local Development

To get started with local development:

```bash
# Clone the repository
git clone [your-repository-url]

# Navigate to the project directory
cd skynex-website

# Install dependencies
npm install

# Start the development server
npm run dev
```

The website will be available at `http://localhost:3000`.

## Technology Stack

- **Framework**: Next.js 15.0.0 (App Router)
- **Frontend**: React 18.2.0
- **Database**: Supabase
- **Styling**: Tailwind CSS 3.4.0
- **Animations**: Framer Motion 11.0.0
- **Icons**: Heroicons 2.1.0
- **Type Safety**: TypeScript
- **Deployment**: Vercel

## Project Structure

The project follows a feature-based structure with App Router:

```
/app                # Next.js App Router routes and pages
/components         # Reusable UI components
/lib                # Utilities, hooks, and shared functions
/public             # Static assets
/styles             # Global styles
```

For more details on the codebase organization and standards, refer to our internal CODE_STANDARDS documentation.

## Deployment

This website is optimized for deployment on Vercel. Simply connect your repository to Vercel for automatic deployments on every push to the main branch.
